# MSC Mods

My mods for MSC:  

**ModsShop** - Shop Catalog mod  
**CDPlayer** - CD Player Enchanced  

## Contributing

> "My Summer Car" installation is required
> "My Winter Car" installation is optional

1. Clone the repository
2. Copy `GamePath.user.sample` to `GamePath.user`
3. Set your game paths in `GamePath.user`
4. Open one of the projects and try to build it
   1. If it is your first time building the project. It might first builds ModsShop.dll.
      1. ModsShop.xml is going to be missing, so get it from NexusMods, I guess...
   2. CDPlayer.dll will be built, only when ModsShop.dll is present / had been built previously
5. Start coding
